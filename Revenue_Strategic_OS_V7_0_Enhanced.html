周權重目標拆解原理
📅 周權重計算：以目標日期的星期幾為基準，查找前一季度 + 去年同月相同星期幾的歷史數據。
🔄 PARALLELPERIOD：返回完整周期（單日→完整月份/季度），與 SAMEPERIODLASTYEAR（單日→單日）的關鍵區別。
📊 三核心數值：實際收入 / 預測收入 / 目標收入，每日監控偏差。
⚙️ 二維表清洗：填充合併單元格 → 篩選空值 → 刪除合計行 → 逆透視 → 添加年月列。
收入分析 DAX 引擎
源自 17 份核心報告的精華公式庫 · 12 個核心度量值 (資料來源：全部 PDF)
1. 動態滾動營收 (Rolling Revenue)
Dynamic Forecast
// 配合 What-If Parameter 實現動態月份推估 Rolling Revenue = CALCULATE( [Total Revenue], DATESINPERIOD('Date'[Date], LASTDATE('Date'[Date]), -[Rolling Months Value], MONTH) )
2. 同比增長率 (YoY Growth)
Trend Analysis
// 注意：分母必須用去年同期值，避免除零錯誤 VAR CurrentRev = [Total Revenue] VAR LastYearRev = CALCULATE([Total Revenue], SAMEPERIODLASTYEAR('Date'[Date])) RETURN DIVIDE(CurrentRev - LastYearRev, LastYearRev)
3. Pareto 80/20 累計佔比
Product Strategy
// 計算當前產品排名以前的所有營收加總 VAR CurrentRank = [Product Rank] VAR TotalRev = CALCULATE([Total Revenue], ALL('Product')) VAR CumulativeRev = CALCULATE([Total Revenue], FILTER(ALL('Product'), [Product Rank] <= CurrentRank)) RETURN DIVIDE(CumulativeRev, TotalRev)
4. ABC 動態分類
Product Strategy
// A≤20% 累計佔比, B 20-50%, C 其餘 ABC Class = SWITCH(TRUE(), [Cumulative %] <= 0.2, "A", [Cumulative %] <= 0.5, "B", "C" )
5. 購物籃提升度 (Lift)
MBA Strategy
// 判斷產品關聯強度 (>1 為正相關，建議捆綁銷售) Lift = DIVIDE( [Confidence], DIVIDE([B_Customer_Count], CALCULATE(DISTINCTCOUNT(Orders[ID]), ALL(Products))) )
6. MBA 置信度 (Confidence)
MBA Strategy
// P(B|A) = 購買 A 後也購買 B 的機率 Confidence = VAR AB_Customers = CALCULATETABLE(VALUES(Orders[CustomerID]), FILTER(Orders, Orders[ProductA] = 1)) VAR AB_Both = INTERSECT(AB_Customers, CALCULATETABLE(VALUES(Orders[CustomerID]), FILTER(Orders, Orders[ProductB] = 1))) RETURN DIVIDE(COUNTROWS(AB_Both), COUNTROWS(AB_Customers))
7. RFM 評分計算
Customer Value
// R=最近消費(越小越好), F=頻率(越大越好), M=金額(越大越好) RFM Score = VAR R_Score = IF([Days Since Last Purchase] <= 30, 1, 0) VAR F_Score = IF([Purchase Frequency] >= 3, 1, 0) VAR M_Score = IF([Total Spend] >= [Avg Spend], 1, 0) RETURN R_Score * 100 + F_Score * 10 + M_Score
8. 月度複購率
Customer Value
// 複購率 = 複購客戶數 / 當期總客戶數 Repurchase Rate = VAR LastMonthCustomers = CALCULATETABLE(VALUES(Orders[CustomerID]), PREVIOUSMONTH('Date'[Date])) VAR ThisMonthCustomers = VALUES(Orders[CustomerID]) VAR RepurchaseCustomers = INTERSECT(LastMonthCustomers, ThisMonthCustomers) RETURN DIVIDE(COUNTROWS(RepurchaseCustomers), COUNTROWS(ThisMonthCustomers))
9. 省份排名 (RANKX)
Region Analysis
// 計算省份收入排名，添加到工具提示 Region Rank = RANKX( ALL('City'[Province]), [Total Revenue], , DESC, DENSE )
10. 預算差異率 (Budget Variance)
Budget Analysis
// 預實差異分析，正值超標，負值缺口 Budget Variance % = VAR Actual = [Total Revenue] VAR Budget = CALCULATE([Budget Amount], TREATAS(VALUES('Date'[YearMonth]), Budget[YearMonth])) RETURN DIVIDE(Actual - Budget, Budget)
11. 周權重目標拆解
Budget Analysis
// 以歷史周權重將月度目標拆解到每日 Daily Target = VAR MonthlyTarget = [Monthly Budget] VAR WeekdayWeight = CALCULATE( AVERAGEX(FILTER(Sales, WEEKDAY(Sales[Date]) = WEEKDAY(MAX('Date'[Date]))), Sales[Revenue]), PARALLELPERIOD('Date'[Date], -3, MONTH) ) RETURN MonthlyTarget * DIVIDE(WeekdayWeight, [Total Week Weight])
12. 財務 BP 路徑分析
Finance BP
// 收入→成本→毛利→費用→利潤 完整路徑 Gross Margin % = DIVIDE([Gross Profit], [Total Revenue]) Net Profit % = DIVIDE([Net Profit], [Total Revenue]) // 應收帳款周轉天數 AR Days = DIVIDE([Avg AR Balance], [Total Revenue] / 365)
